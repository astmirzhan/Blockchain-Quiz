# Agile Dev Exam Prep — Полное описание функционала платформы

## Общая информация

Платформа — это веб-приложение для подготовки к экзамену по Agile-разработке. Содержит **115 вопросов**, разделённых на **части A–I** (9 частей). Вопросы бывают трёх типов: single-choice, multiple-choice и free-text (открытые).

---

## 1. Выбор контента (Секции на главной странице)

На главной странице 4 секции для выбора набора вопросов:

### 1.1 🎯 Mock Exam (Full mock exam)
- Имитация реального экзамена
- Генерирует случайный набор из ~42 вопросов на ~100 баллов
- Большинство баллов приходится на free-text вопросы (~55 баллов)
- Остальные баллы добираются single/multi-choice вопросами
- Максимум 45 вопросов
- Проходной балл — **50%** (вместо стандартных 80%)
- Всегда работает в режиме **Exam** (независимо от выбранного режима)

### 1.2 📚 Choose a part (Выбор по частям)
- Кнопки для каждой части (Part A, Part B, ... Part I) с указанием количества вопросов
- Кнопка **"🔥 All parts — full mix"** — все вопросы из всех частей вперемешку
- При выборе любой части можно выбрать режим (Practice/Exam)

### 1.3 ✍️ Open-answer training (Тренировка открытых ответов)
Фильтрация **только free-text вопросов** по длине ответа:

| Категория | Критерии |
|-----------|----------|
| **Short answers** | Вопрос требует ≤6 слов ИЛИ ≤3 балла |
| **Medium answers** | Вопрос требует 7–20 слов ИЛИ 4–6 баллов |
| **Long answers** | Вопрос содержит слово "phrase" ИЛИ >20 слов ИЛИ >6 баллов |

> [!NOTE]
> Есть список исключений (MEDIUM_OVERRIDES) — вопросы, которые принудительно относятся к категории "medium" независимо от других критериев.

### 1.4 ☑️ Choice questions only (Только вопросы с выбором)
- Все вопросы single-choice и multiple-choice из всех частей
- Free-text вопросы исключаются

## 2. Режимы прохождения (Mode)

### 2.1 Practice (Режим практики)
- **Мгновенная обратная связь** после каждого вопроса
- После нажатия "Check answer":
  - **Single/Multi-choice**: правильные варианты подсвечиваются зелёным ✓, неправильные — красным ✗, пропущенные правильные — пунктирной зелёной рамкой
  - **Free-text**: показывается правильный ответ + количество совпавших ключевых слов (`matched X/Y key words`)
- Фидбэк: `✓ Correct`, `◐ Partial`, `✗ Incorrect` с количеством баллов
- Кнопка "Next question →" для перехода дальше
- На последнем вопросе — кнопка "See results"

### 2.2 Exam (Режим экзамена)
- **Нет обратной связи** после каждого вопроса
- После нажатия "Submit" — сразу переход к следующему вопросу
- Все результаты показываются только в конце
- Проходной балл — **80%** (или 50% для Mock Exam)

## 3. Типы вопросов и их оценка

### 3.1 Single-choice (Один правильный ответ)
- Выбор одного варианта из нескольких
- Оценка: **1 балл** за правильный ответ, 0 за неправильный
- При выборе одного варианта предыдущий автоматически снимается

### 3.2 Multiple-choice (Несколько правильных ответов)
- Можно выбрать несколько вариантов (чекбоксы вместо радио-кнопок)
- Максимум баллов = количество правильных ответов
- Оценка: **+1** за каждый правильный, **-1** за каждый неправильный, минимум 0
- Пример: 2 правильных ответа, выбрано 2 правильных + 1 неправильный = 2 - 1 = **1 из 2**
- Чип "Multiple answers" в метаданных вопроса

### 3.3 Free-text / Written answer (Открытый ответ)
- Текстовое поле для ввода ответа
- Максимум баллов указан в конце вопроса в формате `[N]` (например, `[6]` = 6 баллов)
- Оценка по ключевым словам:
  1. Из правильного ответа извлекаются **ключевые слова** (без стоп-слов)
  2. Текст пользователя сравнивается с ключевыми словами
  3. Балл = `(matched / total_keywords) × max_points`, округлённый
- **Стемминг**: `ies→y`, `ing/edness/edly→∅`, `es/ed/s→∅`
- **Толерантность к опечаткам**: для слов ≥4 символа допускается расстояние Левенштейна ≤1
- **Стоп-слова** игнорируются (a, an, the, of, in, to, and, or, is, are, was, were, be, been, etc.)

## 4. Интерфейс прохождения квиза

### 4.1 Верхняя панель
- **Счётчик**: `1 / 42` (текущий / всего)
- **Кнопка "Exit"**: выход с подтверждением (`confirm('Exit the quiz? Progress will be lost.')`)

### 4.2 Прогресс-бар
- Полоса заполнения: `(текущий_индекс / всего) × 100%`
- Анимация перехода (`transition: width .25s ease-out`)

### 4.3 Метаданные вопроса (чипы)
- **Part X** — к какой части относится
- **Тип**: "Single answer" / "Multiple answers" / "Written answer"
- **Баллы**: "N pts" или "1 pt"

### 4.4 Кнопки действий
- **Practice**: "Check answer" → фидбэк → "Next question →" / "See results"
- **Exam**: "Submit" → сразу следующий вопрос

---

## 5. Экран результатов

### 5.1 Карточка результатов
- **Кольцевая диаграмма** (SVG) с процентом
- Текст: `earned/total` баллов, `XX%`, **PASS** или **FAIL**
- Цвет: зелёный при прохождении, красный при непрохождении
- Порог: `≥80%` = PASS (или `≥50%` для Mock Exam)
- Сообщение:
  - PASS: `✓ Above the X% pass mark — well done! 🎉`
  - FAIL: `✗ Below the X% pass mark — review the items below.`

### 5.2 Обзор ошибок (Review — points lost)
- Показываются **только неправильные/частичные ответы**
- Для каждого: вопрос, часть, набранные/макс баллы
- **Choice**: ваш ответ (красный) + правильный ответ (зелёный)
- **Free-text**: ваш текст (красный) + правильный ответ (зелёный)

### 5.3 Кнопки
- **Home** — вернуться на главную
- **Try again** — повторить тот же набор (перезапуск с перемешиванием)

---

## 6. Перемешивание (Shuffle)

- **Порядок вопросов** перемешивается при каждом запуске (алгоритм Fisher-Yates)
- **Порядок вариантов ответов** в choice-вопросах тоже перемешивается
- Индексы правильных ответов пересчитываются при перемешивании

---

## 7. Техническая архитектура

| Компонент | Реализация |
|-----------|------------|
| Фронтенд | Один HTML-файл, vanilla JS, CSS custom properties |
| Данные вопросов | JS-файл с `window.QUIZ_DATA` (JSON-объект, ключи — части A–I) |
| Хранение состояния | Переменные в памяти (selPart, selMode, quiz[], idx, results[], picked, revealed) |
| Персистентность | Нет — данные теряются при перезагрузке страницы |

---

## 8. Структура данных вопроса

```json
{
  "q": "Текст вопроса [N]",       // [N] — макс. баллы для free-text
  "options": ["A", "B", "C"],      // [] для free-text
  "correct": [0, 2],               // индексы правильных ответов; [] для free-text
  "answer": "Текст ответа"         // null для choice, строка для free-text
}
```

---

## 9. Дизайн и UX

- Светлая тема с CSS custom properties
- Карточки с тенями и скруглениями (`border-radius: 14px`)
- Анимации при наведении и нажатии (`scale(.97)`, `brightness(1.1)`)
- Адаптивная сетка: 2 колонки → 3 колонки на экранах >560px
- Поддержка `prefers-reduced-motion` для отключения анимаций
- Шрифт: системный стек (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Inter`)
